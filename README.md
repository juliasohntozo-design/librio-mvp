📚 Librio

Sistema de gerenciamento de biblioteca escolar desenvolvido como MVP.

🎯 Objetivo

O Librio tem como objetivo facilitar o controle de livros e empréstimos
em bibliotecas escolares, tornando o processo mais simples e organizado.

🚀 Funcionalidades

- Cadastro de livros
- Pesquisa de livros
- Controle de livros disponíveis
- Registro de empréstimos
- Registro de devoluções
- Controle de empréstimos em atraso
- Histórico de empréstimos
- Dashboard com indicadores

💻 Tecnologias

- HTML
- CSS
- JavaScript
- LocalStorage

📌 Status

MVP em desenvolvimento.
